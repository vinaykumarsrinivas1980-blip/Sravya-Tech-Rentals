## 🛠️ Getting Started (Local Development)

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🏗️ Production Build

```bash
cd frontend
npm run build
```

This generates a high-speed, statically optimized build with 100% SEO scores, pre-rendered product detail pages (`/products/[id]`), and an automated sitemap.
